# DigitLab · 阿拉伯数字识别模型（模型归档）

本仓库归档一个**已训练完成的阿拉伯数字（0-9）手写数字串识别模型**，以及它的模型卡、独立推理代码和来源清单。

模型来自本地项目 **DigitLab · 数字识别模型训练与管理软件**（纯 Python 标准库实现，零第三方依赖）。该软件把图像预处理、字符切分、特征提取、可训练分类器、训练调度、评估与截图管理做成了一个本地服务 + 浏览器界面；本仓库只归档其中的**模型本体**。

## 仓库内容

| 路径 | 说明 |
| --- | --- |
| `model/weights.json` | 已训练权重：`sparse_softmax`，256 维特征，10 类（0-9），`W` 为 10×256、`b` 为 10 |
| `model/metadata.json` | 模型版本元数据：版本 ID、训练配置快照、数据集版本、预处理版本与指标 |
| `MODEL_CARD.md` | 模型卡：架构、训练口径、指标、已知限制 |
| `predict.py` | 独立推理脚本：输入 256 维特征向量，输出数字类别、置信度与 10 类概率 |
| `verify_model.py` | 权重自检：结构、形状、数值范围、与元数据一致性、文件指纹 |
| `manifest.json` | 完整软件 27 个源码/文档文件的路径、字节数与 SHA256 清单 |
| `PUSH.md` | 推送到 GitHub 的操作说明 |

## 快速开始

需要 Python 3.9+，无需安装任何依赖。

```bash
python verify_model.py     # 校验权重文件
python predict.py          # 自检：零特征向量的输出分布
python predict.py f.json   # 对 f.json 中的 256 维特征向量推理
```

`f.json` 是一个长度为 256 的数字数组，例如 `[0.0, 0.12, ...]`。输出为 JSON：

```json
{"digit": 3, "confidence": 0.8765, "probabilities": [0.01, ...]}
```

**重要口径**：256 维稀疏特征向量由完整软件的 `digit_lab/core/imaging.py`（预处理版本 `P6-v1`）生成，图像 → 特征的转换不属于本仓库。要用原始图片做端到端识别，需运行完整软件；本仓库提供的是模型层（特征 → 类别）的权重与推理实现。

## 权重文件说明

`model/weights.json` 由原始权重文件 `mdl_20261110094140_0074.json` 规整而来：浮点数保留 8 位小数、按 64 个元素折行、去掉冗余空白，仍是合法 JSON。数值差异小于 1e-8，对 softmax 输出无实质影响；需要逐位一致的原始文件可从本地项目 `digit_lab/data/models/` 获取。

字段：`kind`（`sparse_softmax`）、`n_features`（256）、`seed`（20261109）、`W`（10 行 × 256 列）、`b`（10 项）。类别索引 0–9 对应数字 0–9。
